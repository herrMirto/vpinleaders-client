VPinScore

A score tracker for Visual Pinball X cabinets and desktop setups. Watches your games, captures final scores, and submits results to your favourite leaderboard services.

Platform Setup

macOS arm64

  1. Unzip VPinScore-macOS-arm64.zip
  2. Remove the quarantine attribute:
xattr -d com.apple.quarantine VPinScore-macOS-arm64
  1. Run the client and complete the first-run setup:
./VPinScore-macOS-arm64

Windows x64

  1. Download VPinScore-Windows-x64.zip
  2. Right-click the downloaded .zip, open Properties, and click Unblock
  3. Unzip it
  4. Run the app and complete the first-run setup:
.\VPinScore-Windows-x64.exe

Linux x64

  1. Unzip VPinScore-Linux-x64.zip
  2. Start the app with the bundled launcher and complete the first-run setup:
./vpinst-start.sh

The launcher exists because Linux needs extra permission to read live VPX data. It applies the required capability for the packaged binary:

sudo setcap cap_sys_ptrace=eip /path/to/VPinScore-Linux-x64/VPinScore-Linux-x64
You may be prompted for sudo the first time the launcher runs.

Integrations

First-run setup creates the config file automatically in the correct location:

  • Linux: ~/.config/vpinscore/config.ini
  • macOS: ~/Library/Application Support/VPinScore/config.ini
  • Windows: %APPDATA%\VPinScore\config.ini

After the first run, use the tray menu to open Settings. From there you can enable integrations and choose the display used for screenshots.

VPinPlay

VPinPlay lets the client sync scores to your own local or network VPinPlay instance.

  1. Start your VPinPlay instance.
  2. Open the client tray menu.
  3. Choose Settings.
  4. Enable VPinPlay.
  5. Enter the VPinPlay URL, user ID, and initials. If VPinFE is installed, the client loads these values from vpinfe.ini.
  6. Turn on automatic VPinPlay sending if you want scores synced as soon as a game ends.
  7. Save the settings.

WoVP Challenges

WoVP lets the client submit scores to active challenges.

  1. Sign in at worldofvirtualpinball.com.
  2. Create a WoVP API key in your account settings.
  3. Open the client tray menu.
  4. Choose Settings.
  5. Enable WoVP.
  6. Paste your WoVP API key.
  7. Save the settings.
WoVP submissions require a screenshot. The client captures the configured display when you trigger a manual send.

When WoVP is enabled, the client loads active challenges at startup and shows them in the tray menu. Select the challenge you want to submit to before sending a score.

iScored Gamerooms

iScored lets the client submit scores to an iScored gameroom.

  1. In iScored, make sure your gameroom allows score submissions.
  2. Open the client tray menu.
  3. Choose Settings.
  4. Enable iScored.
  5. Enter your iScored username.
  6. Save the settings.

After iScored is configured, the client loads your gameroom games and shows them under iScored > Games in the tray menu. Select the game you want to submit to before sending a score.

Source Run

If you want to run from source instead of the packaged artifacts:

pip install -r requirements.txt
python3 main.py

Optional explicit config path for development and testing only:

python3 main.py --config /path/to/config.ini

NVRAM Maps

The nvram-maps/ directory contains JSON map files that describe how each pinball ROM stores scores and game state inside its non-volatile RAM (.nv files).

This project makes use of content from the Pinball Memory Maps project, licensed under the GNU Lesser General Public License v3.0 (LGPL-3.0).

The upstream map files are included unmodified where available. A local fork is maintained for two reasons:

  • Extended maps — some ROMs are not yet covered by the upstream project, or need additional game_state fields that go beyond its current scope.
  • Custom conventions — a few maps deviate slightly from the upstream format to accommodate edge cases specific to this client.

The intention is to upstream all compatible additions back to the tomlogic/pinmame-nvram-maps project once they are stable and conform to its file-format conventions.

See the full list of supported ROMs on the Supported ROMs page.
